# Course Installation Guides

Welcome to the installation guide for **Orchestration Fundamentals for Agentic Development**.

To participate in the breakout labs, you will need the following tools installed on your machine:

- **Git** for version control
- **Python 3** to run the local validation scripts
- **Claude Code** (and Node.js as a prerequisite) to participate in the agent orchestration exercises

Please follow the instructions for your operating system:

- [macOS Installation Guide](./install-mac.md)
- [Windows Installation Guide](./install-win.md)
