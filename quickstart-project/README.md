# Verification Quickstart

This project contains a simple script to verify that you have successfully installed all the required dependencies for the course.

## How to Verify Your Setup

Open your terminal, navigate to this directory, and run the verification script:

```bash
python3 verify_setup.py
```

### Expected Output

If all tools are installed correctly, you should see the following success marker:

```
Verifying Course Setup...

✅ Git found: ...
✅ Python 3 found: ...
✅ Claude Code found: ...

------------------------------------------------
🎉 SUCCESS: All required tools are installed correctly!
```

If any check fails, please return to the installation guides and ensure you have completed all the steps for your operating system.
